## Описание модулей

### `mamba.py` — Основная архитектура TSPMamba
Реализует **BiMamba2Block** — двунаправленный SSM-блок на базе Mamba-2 (forward + backward проход с конкатенацией и линейной проекцией). Архитектура принимает признаки рёбер (`edges_feat ∈ R^{E×17}`), текущее состояние (`x_t ∈ R^{E}`), временной шаг (`t ∈ R^{B×E}`) и предсказывает вектор скорости `v_t ∈ R^E`.

Гиперпараметры: `hidden_dim=128`, `num_layers=6`, `d_state=64`, `d_conv=4`.

### `sparse_attention.py` — Разреженное внимание
**SparseAttentionBlock** реализует sliding-window attention: каждое ребро обращает внимание только на соседей в окне размером `window_size=50`. Сложность: O(N·K). Используется для сравнения с BiMamba-2.

### `linear_attention.py` — Линейное внимание
**LinearAttentionBlock** реализует Performer-style линейное внимание (ядровое приближение через `elu(·)+1`). Сложность: O(N). Используется для сравнения с BiMamba-2.

### `flow_matching.py` — Генеративная часть (OT-Flow Matching)
Три режима генерации:
- `ot` — **OT-Flow Matching**: прямые траектории (x_t = (1−t)·x_0 + t·x_1, v_target = x_1 − x_0)
- `vanilla` — стандартный Flow Matching (независимая связь)
- `diffusion` — упрощённая DDPM-like формулировка (для сравнения)

Инференс: ODE-солвер методом Эйлера, `steps=50` по умолчанию.

### `data_preprocessing.py` — Подготовка графа
Формирует kNN-граф (k=20 соседей), нормализует координаты, вычисляет признаки рёбер: евклидово расстояние + синусоидальные позиционные кодировки (16-мерные). Поддерживает режимы сортировки узлов: `tsp` (жадный), `bfs`, `x-coord`. Итоговые признаки: `edges_feat ∈ R^{E×17}`.

### `validation.py` — Оценка качества
Жадный декодер тура из heatmap (с проверкой ограничений степени и цикличности через Union-Find). Метрики:
- `compute_tour_length(coords, tour)` — длина тура
- `tour_gap(pred_length, opt_length)` — GAP (%) относительно оптимума
